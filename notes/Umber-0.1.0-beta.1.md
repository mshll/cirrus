
First beta. Everything below is new.

- Floating markdown panel on a global hotkey, over a folder of plain `.md` files.
- Tiptap editor with headings, lists, task lists, quotes, code blocks, links, and lossless
  round-tripping of markdown it does not model.
- Note switcher (`⌘P`) and actions palette (`⌘K`).
- Settings with panes for General, Editor, Shortcuts, and Updates.
- About window.
- Sparkle updates, with an opt-in pre-release channel.

Not notarised by Apple — see the README for the first-launch step.
